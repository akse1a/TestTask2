# Замер: последовательно против параллельно

Замерялась Фаза реализации контракта `docs/SPEC.md` тремя способами-исполнителями.
**Параллельный прогон выполнен реально** (три субагента одновременно, каждый в своём
worktree). Последовательный прогон **не выполнялся полностью** — вместо него приведена
честная оценка-counterfactual на основе реальных длительностей; это отдельно помечено.

## Что реально измерено (параллельно)

| Метрика | Значение |
|---|---|
| Wall-clock всей фазы (спавн → финиш последнего агента) | **489 c** (~8 мин) |
| Длительность агента A | 329 c |
| Длительность агента B | 448 c |
| Длительность агента C | 398 c |
| Токенов израсходовал агент A (в своём контексте) | 67 347 |
| Токенов израсходовал агент B | 84 298 |
| Токенов израсходовал агент C | 73 714 |
| Суммарно в субагентах | 225 359 |
| Осело в контексте ГЛАВНОЙ сессии | только три коротких отчёта-сводки (~1–2 K токенов каждый) |

Ключевой факт: 225 K токенов работы с кодом **остались в контекстах субагентов** и
**не попали** в главную сессию — та получила лишь финальные сводки. Это ровно тот эффект,
про который говорили на занятии: параллельные агенты экономят не столько время, сколько
**контекст главной сессии**.

## Оценка последовательного прогона (counterfactual, НЕ измерено)

Если бы ту же тройную работу делал один агент подряд в одной сессии:

| Метрика | Оценка | Обоснование |
|---|---|---|
| Wall-clock | ~1175 c (~20 мин) | сумма длительностей 329+448+398, т.к. нет совмещения |
| Контекст главной сессии | ~225 K+ токенов | весь код всех трёх реализаций читался/писался бы в ОДНОМ контексте |

## Вывод

На этой задаче параллельность дала выигрыш **и по времени** (489 c против ~1175 c — здесь
части действительно независимы, три полноценные реализации), **и по контексту** (главная
сессия осталась почти пустой). Оговорка с занятия остаётся верной: на *мелкой* задаче
параллельность бывает медленнее из-за старта субагентов — здесь задача оказалась достаточно
крупной и по-настоящему независимой, поэтому выигрыш по времени тоже появился.

**Честная граница замера:** полный последовательный прогон я не гонял (это стоило бы ещё
~20 минут и ~225 K токенов в главную сессию ради числа, которое и так выводится из
длительностей). Поэтому последовательная колонка — оценка, а не факт.
