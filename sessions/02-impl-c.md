## Что честно отметил агент

1. Идемпотентность на одном атомарном `sync.Map.LoadOrStore` без лока на горячем пути:
   проигравший гонку кандидат отбрасывается и не индексируется по id → сироты не наблюдаемы.
   Reuse — по SHA-256 пары `"<amount>|<currency>"`. Отмена — под per-`Payment` мьютексом.
2. То же окружение: `CC` вёл на MinGW; гонял зелено с `CC=gcc`, глобальный env не трогал.
3. Bash-песочница блокирует спавн gcc из go — гонял с отключённой песочницей.
4. Ограничения: in-memory; записи идемпотентности не эвиктятся (растут за время жизни
   процесса); `captured` не реализован (SPEC §3).
